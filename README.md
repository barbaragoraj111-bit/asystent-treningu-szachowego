# asystent-treningu-szachowego
Aplikacja do planowania i śledzenia postępów w treningu szachowym

## Planowane funkcje
- Rejestrowanie sesji szachowych jak: Debiuty, Końcówki, Skomentowane partie, Taktyka, Zadania gra pozycyjna, Turniej.
- Śledzenie czasu poświęconego na poszczególne elementy treningu.
- Ustawienie celu treningowego i monitorowanie postępu.
- Ustawianie na szachownicy pozycji ze zdjęcia.
